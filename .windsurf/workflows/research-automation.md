# Research Automation Workflow

This workflow automates the research and validation of documentation, APIs, and best practices for project planning.

// turbo-all

1. **Initialize Research Framework**
   - Set up research parameters and scope
   - Define documentation source priorities
   - Configure search engines and APIs
   - Initialize result caching system

2. **Documentation Source Prioritization**
   - **Official Documentation**: Prioritize official framework/library docs
   - **GitHub Repositories**: Check official repos for latest changes
   - **Community Resources**: Include Stack Overflow, dev.to, Medium
   - **API Documentation**: Focus on OpenAPI specs and official API docs
   - **Version-Specific Sources**: Ensure version compatibility

3. **Automated Research Execution**
   - **Web Search Integration**: Search for current best practices
   - **API Endpoint Validation**: Test API accessibility and responses
   - **Documentation Freshness Check**: Verify last update dates
   - **Breaking Change Detection**: Scan changelogs and release notes
   - **Community Sentiment Analysis**: Check for common issues/solutions

4. **Research Result Validation**
   - **Source Credibility Scoring**: Rate sources by authority and recency
   - **Information Consistency Check**: Cross-validate information across sources
   - **Version Compatibility Verification**: Ensure compatibility with project requirements
   - **Completeness Assessment**: Identify gaps in research coverage

5. **Research Report Generation**
   - **Executive Summary**: Key findings and recommendations
   - **API Status Report**: Validation results for all APIs
   - **Documentation Quality Score**: Freshness and completeness metrics
   - **Risk Assessment**: Potential issues and breaking changes
   - **Recommendation Matrix**: Prioritized action items

6. **Research Failure Fallback Mechanisms**
   - **Cached Results**: Use previous research if current fails
   - **Alternative Sources**: Fallback to secondary documentation sources
   - **Manual Research Prompts**: Guide user to manual research when needed
   - **Partial Results Handling**: Proceed with available information
   - **Error Reporting**: Clear communication of research limitations

7. **Research Result Integration**
   - **Context Enhancement**: Integrate findings into planning context
   - **Template Adaptation**: Adjust templates based on research findings
   - **Risk Mitigation**: Include preventive measures for identified risks
   - **Best Practice Integration**: Incorporate discovered best practices

8. **Research Caching and Persistence**
   - **Result Caching**: Store research results for reuse
   - **Cache Invalidation**: Refresh cached results based on age/changes
   - **Research History**: Maintain history of research for pattern analysis
   - **Knowledge Base Update**: Contribute findings to organizational knowledge

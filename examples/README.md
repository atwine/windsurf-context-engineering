# Code Examples

This directory is for storing concrete code examples that help guide the AI coding assistant.

## Purpose

When you kick off a new project using `initial-prompt-template.md`, you can reference files in this directory.

Providing specific, working examples is one of the most effective ways to improve the quality of the AI's output. It helps with:

- **Style and Convention:** Shows the desired coding style.
- **Complex Logic:** Provides a clear implementation for a tricky algorithm or API call.
- **Authentication:** Demonstrates the correct way to handle credentials.

## How to Use

1.  Add a new file here (e.g., `my-auth-pattern.py`).
2.  In your initial prompt file, reference it under the `Code Examples` section, explaining what it demonstrates.
